# 项目结构清单（带注释）

> 适用于 `smart-assistant-java/`（IPAS 智能助手）。
> 本文档只做"说明"，不改变任何代码。目录与包名均以**当前实际状态**为准。
> 组织方式：前后端分离（`backend/` + `frontend/`）；**后端按"层"分包，前端按"类型"分目录**。

---

## 〇、顶层布局

```
smart-assistant-java/
├── backend/            Spring Boot 后端（Maven 工程根，pom.xml 在这层）
├── frontend/           React + TypeScript + Vite 前端
├── docs/               说明文档（学习文档 / 项目结构清单 / 优化记录 / 答辩面试手册）
├── tools/              辅助脚本
│                       ├── mock_openai.py      本地假 OpenAI 服务（离线联调）
│                       ├── start-minio.bat     启动本地 MinIO（可选对象存储后端）
│                       └── start-pgvector.bat  启动 WSL 里的 PostgreSQL（可选向量检索后端）
├── start.sh / start.bat  一键启动前后端（会检查前端依赖是否已装）
├── README.md           使用说明（安装 / 启动 / 可选后端 / 验证）
├── .editorconfig       缩进与换行规则（Java 4 空格 / TS·CSS·JSON·YAML 2 空格 / .bat CRLF）
├── .gitignore          项目级忽略规则
└── .navicat-probe.txt  临时探针文件（含凭据，已 gitignore；是否删除待定）
```

**为什么是"前后端分开"**：前端是 React 单页应用、后端是 Spring Boot 服务，
两者互不依赖源码，只通过 `/api`（HTTP）交互，物理分开便于各自独立构建/部署。

### 1.3 后端关键约定（改代码前必读）

- **接口契约**：JSON 一律 `snake_case`；错误体 `{"detail": "中文提示"}`；状态码 400 业务校验 / 401 未认证 / 404 不存在（不外泄存在性）/ 422 框架校验；时间是不带时区的 ISO 字符串（存 UTC）。
- **SSE 五类事件**：`token` / `reasoning` / `sources` / `done` / `error`，逐字对齐原版，前端零改动。
- **`@RequestBody` 必须配 `@Valid`**，`@RequestParam` 的校验必须给控制器类加 `@Validated`（否则静默失效）。
- **`DataDirProvider` 是数据目录的唯一来源**（库中 `system.data-dir` ＞ yml 默认），改完立即生效；不要直接读 `AppProperties.dataDir()`。
- **Agent 相关 Bean 标 `@Profile("!test")`**：`MysqlSaver` 构造即连库，契约测试（不依赖 MySQL）整体排除它们。
- **服务层 `requireOwned(userId,id)`** 取不到一律抛 404（不抛 403），避免泄露资源是否存在。
- **`@RequestParam` 一律显式写 `value = "snake_case"`**：裸 `@RequestParam` 取的是**编译后的参数名**（驼峰），与前端/Python 原版的 `snake_case` 契约不符 → 返回 422；而前端 `.catch` 常常把错误静默吞掉，表现为"页面一片空白"。**参数名也是契约的一部分。**
- **环境变量驱动的开关必须在 `application.yml` 里声明**（`xxx: ${ENV_NAME:default}`）：Spring **不会**把任意环境变量映射到自定义配置键。漏写不会报错，只会**静默失效**（踩过两次：两个回填开关都不触发）。
- **两条检索路的结构必须一致**：`RagService` 的"MySQL 内存算余弦"与"pgvector 检索"产出同一组映射（`Candidates`），下游的融合/门控/扩窗/预算因此不需要区分来源 —— 外部依赖缺席时能干净退让。
- **可选依赖用 `ObjectProvider<T>` 注入**：`VectorIndexPort` 只在 `vector-store=pgvector` 时才是 Bean，直接注入会让默认模式启动失败。

## 四、常见操作速查
